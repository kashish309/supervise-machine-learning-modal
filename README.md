# Supervised Machine Learning Projects

## Overview

This repository contains the implementation of supervised machine learning algorithms for regression and classification problems. Each project follows a complete machine learning pipeline, including data preprocessing, feature engineering, model training, prediction, and performance evaluation.

## Projects

### 1. Linear Regression – House Price Prediction

* Predicts house prices based on property features.
* Evaluated using regression metrics such as Mean Absolute Error (MAE), Mean Squared Error (MSE), and R² Score.

### 2. K-Nearest Neighbors (KNN) – Fraud Detection

* Classifies transactions as fraudulent or non-fraudulent based on the nearest neighbors.
* Evaluated using Accuracy, Precision, Recall, F1-Score, and Confusion Matrix.

### 3. Logistic Regression – Loan Prediction

* Predicts whether a loan application will be approved.
* Evaluated using Accuracy, Precision, Recall, F1-Score, and Confusion Matrix.

### 4. Decision Tree – Classification

* Builds a decision tree to classify data based on feature values.
* Easy to interpret and suitable for both numerical and categorical data.

### 5. Random Forest – Classification

* Uses multiple decision trees to improve prediction accuracy.
* Reduces overfitting and provides reliable classification performance.

### 6. Support Vector Machine (SVM) – Disease Prediction

* Classifies patients into disease and non-disease categories.
* Effective for binary classification and high-dimensional datasets.

### 7. XGBoost – HR Attrition Prediction

* Predicts employee attrition using the XGBoost algorithm.
* Provides high accuracy and robust performance through gradient boosting.
